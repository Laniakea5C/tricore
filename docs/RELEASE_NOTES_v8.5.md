# TriCore v8.5

> 我把电子信息四年的学习路线，做成了赛博朋克 2077 的技能树。

这次更新把「能看」变成了「能用」：AI 导师真正跑起来了，进度能备份了，图谱也不再飘字。

## 新东西

**AI 导师**
- 接入 11 家模型：DeepSeek、智谱 GLM、Kimi、Qwen、OpenAI、Claude、Grok、Gemini、MiniMax、MiMo，再加一个自定义入口
- 三种协议：OpenAI 兼容 / Anthropic / Gemini，冷门网关也能接
- 模型列表点「查询」就出来，点一下填入，能看上下文和输出上限
- 流式输出，字一个个蹦出来；DeepSeek / Claude / Gemini 的思考过程单独折叠展示
- 拍照、相册、文本文件都能发；教材截图、电路图、波形都能讲
- 会话能新建、切换、导出，切标签不丢
- 每个厂商的 token 用量分开统计

**进度**
- 章节勾选，书籍 / 方向 / 全局三档进度
- 导出成 JSON、粘贴导入、二次确认重置

**声音**
- 图谱页有 4 分钟暗色氛围，全部由代码合成，没有一个字节的版权素材
- 点击是 140 毫秒的机械开关声，开是升调、关是降调
- 循环点做了 4 秒交叉淡化，戴耳机听不出接缝

## 修好的

- 流式回答里成串的 `nullnullnull`——`org.json` 把 JSON `null` 读成字符串 `"null"`，现在统一安全取值
- 切标签回来变成新对话——当前会话 ID 和消息现在会持久化
- 长回答被截断——DeepSeek 思考 64K、普通 8K，Claude 带思考 8K
- 图谱标签拖动时乱飘、画面外的文字被拉回屏幕边缘——标签回到同一套画布变换里，出屏即不画
- 顶栏挤压换行——顶栏只留必要图标，标题单行

## 顺手补的

- 助手回复支持 Markdown：代码块、表格、标题、列表、引用、行内代码
- AI 页全屏，去掉 App 标题和搜索按钮；输入框最多长到 6 行
- DeepSeek 联网搜索走官方 `/v1/tools/search`，回答带来源
- 学习路线把硕博和业界并进三个方向，配书籍、章节、工具链和积累项目

## 已知问题

- Gemini 还没做流式
- 附件只读文本类文件，PDF / Word 不解析
- 图谱密集区标签仍可能轻微重叠
- AI 功能需要自备 Key，仓库里没有任何密钥

## 安装

下载 `TriCore-App-v8.5-release.apk`，Android 8.0（API 26）及以上，直接安装即可。所有学习数据离线内置，不联网也能用。
