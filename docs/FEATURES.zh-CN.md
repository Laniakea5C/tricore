## 学习路线 · 从大一到业界，一条线走完

不是一份书单，是一条**带时间轴、带书目、带验收标准**的路线。

- **按方向**：选一个方向，只看你要学的课；研一、研二、博士、业界 Q1–Q4 全部并入同一条主线
- **按阶段**：切到学期视角，看同一学期三个方向一起要学什么
- **方向标签**：每门课都标着「共同基础 / AI / 芯片 / 机器人」，一眼分清必修与共享
- **深造与就业**：每个阶段都配了书籍、章节、工具链和业界积累项目，写完就能照着做

> 大多数规划表停在「大四考研」，我们把硕士、博士、业界前两年也一起排完了。

## AI 学习导师 · 一个入口，接通 11 家模型

- **厂商**：DeepSeek、智谱 GLM、Kimi、Qwen、OpenAI、Claude、Grok、Gemini、MiniMax、MiMo，外加「自定义 / 第三方」
- **协议**：OpenAI 兼容 / Anthropic / Gemini 三种原生协议，冷门网关也能接
- **模型查询**：填 Key 点「查询」，模型列表直接弹出来，点一下填入，还能看上下文 / 输出长度
- **流式回答**：字一个个蹦出来，不用干等
- **思考过程**：DeepSeek / Claude / Gemini 的推理内容单独折叠展示，看得见它怎么想
- **联网搜索**：DeepSeek 官方搜索 API 直连，回答带来源
- **多模态**：拍照、相册、文本文件，教材截图、电路图、波形都能发给它
- **会话**：新建、切换、删除、导出，切标签不丢
- **用量**：每个厂商输入 / 输出 token 分开统计

> 一个 App 里把国内外主流模型全部打通，还带思考过程和多模态——这件事目前做到的并不多。

## 声音设计 · 给赛博义体装上启动音

这不是"加个 BGM"，这是**在手机里现场合成一套属于你的赛博音景**。

### 4 分钟、5,292,000 个采样点，一个字节素材都没用

打开图谱页，听到的暗色低频不是下载来的循环包，而是启动时由代码**逐采样算出来**的：

- **底噪场**：E1 / B1 / E2 三组锯齿波，每组三重失谐（±0.38%），经过两级低通，变成缓慢呼吸的暗色嗡鸣
- **噪声潮汐**：白噪声低通后叠 0.025 Hz 的极慢涌动，像机房深处的风
- **12 声低频钟**：每 20 秒一次，E3 / B2 / G2 / E2 循环，9 秒衰减
- **心跳低频**：每 10 秒一记 41.2 Hz 的次低频脉冲，安静时能听见自己的"义体心跳"
- **暗色混响**：三条梳状延迟（173 / 211 / 293 ms）并联，再经 tanh 饱和

> 一句话：**别人的 App 放歌，我们的 App 现场写歌。**

### 循环没有接缝

所有调制周期（0.05 Hz / 0.1 Hz / 0.025 Hz）都整除 240 秒，结尾再叠 **4 秒交叉淡化**，所以循环点听不出来——你戴耳机学两小时，也不会被"咔"一下打断。

### 22.05 kHz 单声道，为什么反而更高级

- 用 `AudioTrack` 流式写入，**不占 SoundPool 内存**，长循环也不怕
- 22.05 kHz 单声道把数据量压到 1/4，手机解码和功耗更低
- 首次启动后台线程合成一次，PCM 缓存到本地，之后秒开
- 全程**零网络请求、零版权素材、零第三方音频库**——审核和商用都不存在版权风险

### 点击音：140 毫秒的"机械手感"

每一次点按不是"叮"，而是一次**塑料开关的物理回弹**：

- 高通噪声脉冲做"咔"的起振（1.8 ms 攻击）
- 220 Hz + 330 Hz 双正弦做"壳体"
- 1.32 kHz 边缘谐振做"金属感"
- 21 ms 短延迟做房间尾音，tanh 轻饱和

而且**音高按语义变化**：打开用升调（×1.10）、关闭用降调（×0.90）、确认、发送、切换标签各有细微差别——你闭着眼都能听出自己点的是"开"还是"关"。

### 细节控的三个坚持

1. **音乐和音效彻底解耦**：关掉 BGM，点击音照常响；静音党也能有手感
2. **只有图谱页放音乐**：看路线、查工具、聊天时自动安静，不打扰思考
3. **开关记忆**：关一次，下次进来还是关的——不替你决定

> 别人把声音当装饰，我们把它当**交互的一部分**。
> 赛博朋克不是霓虹配色，是每一次点按都有回声。
